Política de Privacidade

Última atualização: 23 de agosto de 2026.

Esta política descreve como eu, Jordan Estevão, trato dados ao usar ferramentas pessoais de integração que desenvolvo para gerenciar minhas próprias atividades profissionais — incluindo, atualmente, uma integração pessoal com a Google Ads API.

Quem sou e para que uso essas ferramentas

Sou consultor independente na área de automação e transformação operacional. As ferramentas que desenvolvo com acesso a APIs de terceiros (como a Google Ads API) são de uso pessoal e interno, para gerenciar e analisar minhas próprias contas — nunca para prestar serviço, revender acesso ou gerenciar dados de terceiros.

Quais dados são acessados

Ao autorizar uma dessas ferramentas via OAuth (por exemplo, com a sua própria conta Google, no caso da integração com o Google Ads), a ferramenta acessa apenas os dados da sua própria conta de anúncios que você autorizou — como métricas de campanhas (impressões, cliques, custo, conversões) e configurações da conta necessárias para relatórios e, quando aplicável, gestão de campanhas.

Como os dados são usados e armazenados

Os dados são processados localmente, em scripts rodando na minha própria máquina, apenas para geração de relatórios e gestão das minhas campanhas. Credenciais de acesso (tokens, chaves de API) são armazenadas localmente em arquivos de configuração, nunca em código-fonte público, e nunca são compartilhadas com terceiros.

Compartilhamento com terceiros

Os dados acessados pelas ferramentas pessoais de integração descritas acima (como a integração com a Google Ads API) não são vendidos, compartilhados ou transmitidos a terceiros — esse processamento acontece inteiramente no meu próprio ambiente local. Já os dados que você mesmo envia por este site (como o formulário de contato) e os dados de navegação neste site passam pelos serviços de terceiros descritos nas seções abaixo.

Formulário de contato

O formulário de contato deste site é processado pelo Formspree, um serviço de terceiros que recebe os dados que você preenche (nome, empresa, e-mail, WhatsApp, e as demais informações do formulário) e os encaminha para o meu e-mail. Uso esses dados apenas para retornar o seu contato sobre o diagnóstico solicitado — não são usados para nenhuma outra finalidade nem repassados a mais ninguém.

Google Tag Manager

Este site usa o Google Tag Manager para entender como os visitantes usam a página (por exemplo, quais seções são mais acessadas) e para carregar as demais ferramentas de medição descritas nesta política. Nenhum dado é vendido ou compartilhado além do necessário para essa análise.

Meta Pixel e publicidade

Este site usa o Meta Pixel (Facebook/Instagram) para medir a performance dos anúncios que veiculo e entender quais páginas os visitantes acessam, incluindo quando um formulário é enviado. A Meta recebe informações sobre a sua navegação neste site e pode usar esses dados, junto com sua conta Meta (se você tiver uma), para exibir anúncios personalizados a você em suas plataformas. Não envio dados pessoais identificáveis (como nome, e-mail ou telefone) para a Meta através do pixel. Para saber mais sobre como a Meta usa esses dados ou para ajustar suas preferências de anúncios, acesse as Configurações de anúncios da Meta. Você também pode bloquear esse tipo de rastreamento usando as configurações de privacidade do seu navegador ou extensões de bloqueio de rastreadores.
